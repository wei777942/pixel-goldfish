# 撈金魚 · Pixel Goldfish Scooping

Two-player party game. Open `index.html` on a big screen, scan the QR code with two phones.
Plain HTML canvas + vanilla JS, no build step. See `relay.js` for the account-free relay (public Nostr relays over WSS).
Vendored: `vendor/qrcode.js` (MIT), `vendor/noble-secp256k1.min.js` (MIT), `fonts/` Fusion Pixel Font 12px subset (OFL).
